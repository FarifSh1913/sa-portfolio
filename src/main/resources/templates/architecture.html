    Пользователь создаёт документHTTPS-запрос проходит через Caddy.

    REST API принимает запросPortfolio Web передаёт команду в Document Service.
  3. 03
    Документ сохраняетсяСервис фиксирует данные в PostgreSQL.
  4. 04
    Публикуется document.createdKafka принимает доменное событие.
  5. 05
    Workflow получает событиеConsumer валидирует контекст процесса.
  6. 06
    Camunda запускает согласованиеСтартует Document Approval workflow.
  7. 07
    Результат возвращается в KafkaСтатус становится новым событием.
  8. 08
    Audit сохраняет историюПолный след изменений доступен для контроля.
